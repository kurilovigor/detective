# Экспорт в YOLO
Эта инструкция поможет вам экспортировать аннотации в формат YOLO для использования в задачах 
компьютерного зрения. Для этого пользователь нажимает на пункт меню "Экспорт в YOLO" 
и выбирает файл для экспорта.

В ходе экспорта, выполняются следующие шаги:

1. **Выбор файла для экспорта**: Пользователь выбирает путь и имя файла, в который будут сохранены метки в формате YOLO. 
2. **Экспорт меток**: Система экспортирует метки в выбранный файл в формате YOLO. 
3. **Экспорт аннотаций**: Система экспортирует аннотации в отдельные файлы для каждого изображения, если это необходимо. 

## Выбор файла для экспорта
Файл для экспорта должен быть выбран пользователем через диалоговое окно.
Пользователь может указать путь и имя файла, в который будут сохранены метки в формате YOLO.
Расширение файла должно быть yml. Имя по умолчанию data.yml. Пользователь может изменить имя файла и путь по своему усмотрению.
Используются стандартные диалоговые окна для выбора файла, которые предоставляются WPF.

## Экспорт меток
Метки экспортируются в файл в формате YML, который содержит информацию о классах объектов.

```yaml
# Пример содержимого файла data.yml
train: ../train/images
val: ../valid/images

nc: 3
names: ['head', 'helmet', 'person']
```

Здесь:
- train: путь к папке с обучающими изображениями
- val: путь к папке с валидационными изображениями
- nc: количество классов
- names: список названий классов

## Экспорт аннотаций
Для каждого изображения создается отдельный файл с аннотациями в формате YOLO.
Класс FileEntity используется для представления информации об изображении и его аннотациях.
Формат аннотаций YOLO включает координаты ограничивающих рамок и идентификаторы классов.
Пример содержимого файла аннотаций для изображения:
```
1 0.617 0.3594420600858369 0.114 0.17381974248927037
1 0.094 0.38626609442060084 0.156 0.23605150214592274
1 0.295 0.3959227467811159 0.13 0.19527896995708155
1 0.785 0.398068669527897 0.07 0.14377682403433475
1 0.886 0.40879828326180256 0.124 0.18240343347639484
1 0.723 0.398068669527897 0.102 0.1609442060085837
1 0.541 0.35085836909871243 0.094 0.16952789699570817
1 0.428 0.4334763948497854 0.068 0.1072961373390558
1 0.375 0.40236051502145925 0.054 0.1351931330472103
1 0.976 0.3927038626609442 0.044 0.17167381974248927
```

Здесь каждая строка представляет собой аннотацию для одного объекта на изображении:
- Первый столбец: идентификатор класса объекта (начиная с 0)
- Второй столбец: координата x центра ограничивающей рамки (относительно ширины изображения)
- Третий столбец: координата y центра ограничивающей рамки (относительно высоты изображения)
- Четвертый столбец: ширина ограничивающей рамки (относительно ширины изображения)
- Пятый столбец: высота ограничивающей рамки (относительно высоты изображения)

Имя файла совпадает с именем изображения, но с расширением .txt. Например, для изображения image1.jpg будет создан файл image1.txt с аннотациями.
